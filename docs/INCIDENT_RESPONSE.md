# Incident response
Proposed procedure: detect and triage; restrict affected access, disable calls or checkout if needed; preserve restricted evidence; rotate compromised secrets and revoke sessions; assess affected data and users; restore from verified state; validate remediation; communicate to affected users and authorities as required by applicable law; document lessons and corrective actions. Never include PII in public issues. Assign incident owner, private contact, escalation coverage and jurisdiction-specific notification deadlines before launch. Exercise restoration and call-cost emergency stop before enabling real calls.
